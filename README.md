# 🌤 Telegram Weather Bot v2.1

Персонализированный Telegram-бот для прогноза погоды с рекомендациями по одежде, информацией о праздниках и настраиваемыми уведомлениями по Московскому времени.

## ✨ Возможности

- 🌤 **Текущая погода** — актуальные данные для любого города мира
- 📅 **Прогноз на 3 дня** — с почасовой детализацией
- 👗 **Рекомендации по одежде** — на основе температуры
- 🎉 **Информация о праздниках** — государственные праздники РФ
- ⏰ **Настраиваемые уведомления** — до 4 раз в день по МСК
- 🔄 **Адаптивные дайджесты** — с учетом времени суток

## 🛠 Технологии

- **Python 3.12**
- **python-telegram-bot 20.6** (асинхронный фреймворк)
- **APScheduler** (планировщик задач)
- **SQLite** (база данных)
- **OpenWeatherMap API** (погодные данные)
- **pytz** (работа с часовыми поясами)
